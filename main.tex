\reportheading{2.2--2.5 / PYTORCH BUNDLE ADJUSTMENT}{Initialization and convergence}

\textbf{Initialization.}
The last listed image defines the world frame. RANSAC estimates essential matrices
against that reference. The seed pair maximizes median triangulation angle times
inlier count. Its triangulated points place the other cameras at a shared scale via
PnP. All registered views then contribute to linear triangulation. Tracks without
reliable positive depth start on their reference rays at the seed's median depth.

\textbf{Gauge and objective.}
The last pose is fixed at identity rotation and zero translation. The first point
has unit depth in this frame. The optimized parameters are \(3(F-1)\) axis-angle
entries, \(3(F-1)\) translations, and \(3N-1\) point coordinates. Camera \(f\) maps
world point \(X_n\) to \(q_{nf}=R_fX_n+t_f\). For an observed calibrated point
\(x_{nf}\), the loss is
\[
L=\frac{1}{NF}\sum_{n=1}^{N}\sum_{f=1}^{F}
\left\lVert \frac{q_{nf,xy}}{q_{nf,z}}-x_{nf}\right\rVert_2^2 .
\]

Both runs used 10,000 Adam updates, with a cosine schedule annealing the learning
rate from 0.001 to 0.000002. The notebook saves observed points in red and
reprojected points in blue every 1,000 steps, including step zero.
\reportfigure{figures/loss_curves.png}{2.2in}{Mean squared calibrated reprojection error on a logarithmic vertical axis.}
\reportfigure{figures/sift_reprojection.jpg}{1.42in}{Final SIFT reprojection after 10,000 updates.}

\textbf{Why the loss remains positive.}
SIFT converged to \(1.766\times 10^{-4}\) and LoFTR to \(7.353\times 10^{-7}\).
Localization error, inconsistent matches, and residual camera-model error can make
the observed rays incompatible with a single set of poses and 3D points. SIFT's
median was 5.71 px and its maximum was 927 px. Squaring the residuals gives those
large errors a strong influence on the fit.

\clearpage
\reportheading{3 / LOFTR TRACKS AND RECONSTRUCTION}{Matching across five views}

The pretrained outdoor LoFTR model ran on \(800\times600\) grayscale inputs.
IMG\_8657 occupied the first input in every pair, so its returned keypoints
shared the same coarse grid. Matches with confidence above 0.5 passed through
fundamental-matrix RANSAC using a 2 px threshold in the resized images.
Intersecting the verified reference points across all four pairs yielded 175
five-view tracks. The code reverses resizing before applying the inverse intrinsics.
\reportfigure{figures/loftr_reprojection.jpg}{1.42in}{Final LoFTR reprojection in its recorded image order.}

\subsection*{Comparison with COLMAP}
\reportfigure{figures/reconstructions.png}{1.9in}{The two PyTorch results are aligned to the COLMAP camera centers by image name using one similarity per run. Frusta share the same display scale and view angle.}

All three camera trajectories follow the same arc. COLMAP recovers a denser
cloud because it incorporates more observations and accepts tracks shorter than
five views. LoFTR agrees more closely with COLMAP on this sequence. After
alignment, the camera-center RMS is 1.94\% of the longest COLMAP baseline for SIFT
and 0.14\% for LoFTR. The median camera rotation differences are
\(2.98^\circ\) and \(0.18^\circ\), respectively.

\textbf{Parameter exports.}
\texttt{colmap\_parameters.npz} contains the SIFT fit for \S2.5 and
\texttt{loftr\_parameters.npz} contains the LoFTR fit for \S3.2. Both store
world-to-camera axis angles, translations, and 3D points.
